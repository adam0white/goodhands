# Good Hands

A static web game about judging people. You run a small placement agency in Izmir for one November. Families need a nanny, a cook, a carer or a driver; candidates wait on your bench. Nobody is quite who they say at interview. You vouch for them, and your word goes through the door with them.

Play: https://goodhands.adamwhite.work

The authority is [docs/design.md](docs/design.md). Built on [Human Framework](https://github.com/adam0white/human-framework) 2.9.0. Adam accepts the increment by playing it.

```fish
npm install
npm run dev     # local play
npm run check   # lint, typecheck, tests
npm run deploy  # check, build, wrangler deploy
```
